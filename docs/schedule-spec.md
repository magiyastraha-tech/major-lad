# «Мажорный лад Расписание» — как устроено

Вторая программа в этом же репозитории: отдельный exe, отдельная папка
`Data` рядом с ним. Исходный текст задачи — `docs/schedule-spec-source.txt`,
этот файл фиксирует принятые решения.

## Файлы программы

Рядом с exe: `Data` (данные) и `Sound` (звуки напоминаний).

Данные — одна база SQLite `Data/Мажорный лад Расписание.db` (таблицы
`students`, `subscriptions`, `lessons`, `payments`). Каждое изменение
пишется транзакцией, поэтому сбой посреди записи не оставляет половину
таблицы.

Рядом с базой программа сама поддерживает текстовые файлы — их удобно
читать диктором и открывать в блокноте:

- `Data/Students/` — на каждого ученика файл `Имя Фамилия.txt`: имя и
  фамилия, когда куплен абонемент, с какого числа он действует, сколько
  уроков всего, сколько проведено и осталось, телефон, онлайн или очно,
  тип занятия (вокал, акустическая гитара и т. д.), ближайший урок.
- `Data/Проведённые уроки.txt` — проведённые уроки, новые сверху:
  «Алёна Пупкина, 20.11.2026, уроки 5 из 8.».
- `Data/расписание.txt` — уроки на месяц вперёд от сегодняшнего дня
  (не от даты покупки абонемента), отменённые не попадают.

Эти файлы — зеркало базы, а не второй источник правды. Программа
перезаписывает их сама после каждого сохранения и при запуске, ручные
правки в них не читаются обратно. Свои файлы в `Data/Students/`
программа не трогает: удаляет она только те `.txt`, которые сама же
создала (их первая строка — служебная шапка).

- При первом запуске версии с базой программа сама переносит данные из
  старых `Ученики.txt`, `Абонементы.txt`, `Расписание.txt`,
  `Журнал оплат.txt`, а сами файлы убирает в `Data/Архив старой версии`
  (не удаляет).
- Каждый запуск перед открытием базы делает копию в `Data/Резерв`
  (одна на день, хранятся последние 14).
- F9 выгружает все данные читаемым текстом в `Data/Выгрузка.txt` — для
  диктора и для проверки глазами.
- `Data/Настройки.txt` — сочетания клавиш, которые ты настроил сам.

## Звуки

Папка `Sound` рядом с exe: `Напоминание.wav`, `Начало урока.wav`,
`Конец урока.wav`. При первом запуске программа создаёт их сама
(высокие, средние и низкие тона — их трудно перепутать). Чтобы поставить
свой звук, положи файл с тем же именем поверх — программа не
перезаписывает уже существующие. Что за что отвечает — в
`Sound/Как заменить звуки.txt`. Если звук не проигрался, программа
подаёт системный писк, чтобы напоминание не осталось немым.

## Код

| Файл | Что делает |
| --- | --- |
| `schedapp/paths.py` | папка программы, `Data`, `Sound` |
| `schedapp/dates.py` | даты и время словами для диктора |
| `schedapp/store.py` | модели, база данных, перенос из старых txt |
| `schedapp/mirror.py` | текстовые файлы `Students/`, `Проведённые уроки.txt`, `расписание.txt` |
| `schedapp/uikit.py` | `Announcer` (объявления диктору), фильтр горячих клавиш |
| `schedapp/settings.py` | сочетания клавиш: чтение и запись `Настройки.txt` |
| `schedapp/sounds.py` | звуки напоминаний, создание и проигрывание |
| `schedapp/updater.py` | проверка обновлений, докачка, подмена exe и перезапуск |
| `schedapp/reminders.py` | напоминания и вопросы об уроке |
| `schedapp/ui.py` | окна: список учеников, расписание, карточка, формы, настройки |
| `schedule_main.py` | точка входа, из неё собирается exe |

## Логика урока

- Напоминания: за день, за час, за 10 минут до начала.
- В начале урока — «идёт ли урок?». Ответ «да» — через 40 минут вопрос
  «прошёл ли урок?». Нет ответа — повтор через час.
- «Прошёл» — урок помечается `проведён`, счётчик абонемента +1, сумма идёт
  в журнал оплат. «Нет» — урок помечается `отменён`.
- «Докупить уроки» в карточке прибавляет уроки к действующему абонементу
  (второй абонемент не заводится, счётчик остаётся «уроки 3 из 16»).
  Оплата ложится в журнал отдельной строкой, поэтому попадает в F5.
  Покупка абонемента при заведении ученика тоже пишется в журнал.
- Абонемент хранит две даты: когда куплен и с какого числа действует.
  При заведении ученика и при первом пополнении дату начала можно
  выбрать — она и попадает в карточку и в файл ученика.
- Формат и тип занятия у урока по умолчанию берутся из карточки ученика.
- Окно не закрывается, а уходит в трей: напоминания продолжают работать.

## Обновления

Кнопка «Проверить обновления» в настройках: программа спрашивает релизы
GitHub, находит последний с меткой `schedule-v…` и файлом
`MajorLad-Schedule.exe`, скачивает с докачкой, подменяет exe и
перезапускается сама. Проценты проговариваются диктором каждые 10%,
затем «скачано, устанавливаю», затем «программа перезапускается».
Проверка идёт в отдельном потоке, окно не подвисает.

Если установить не удалось (нет прав на запись в папку программы,
оборвалась сеть) — программа говорит об ошибке словами и остаётся
работать; данные в `Data` при этом не затрагиваются.

## Настройки и горячие клавиши

F10 (или кнопка «Настройки», или пункт в меню в трее) открывает окно с
двумя разделами:

- «Общее» — версия программы, «Проверить обновления», «Выгрузить данные
  в текст», «Открыть папку Данные».
- «Сочетания клавиш» — поле на каждую команду программы: карточка
  ученика, уроки на сегодня, уроки на завтра, заработок за месяц,
  выгрузка данных, настройки. Сохранить — и клавиша работает сразу, без
  перезапуска. Одна и та же клавиша на две команды не встанет: программа
  скажет, где она уже занята. «Сбросить по умолчанию» возвращает F2–F5,
  F9, F10.

Сочетания хранятся в `Data/Настройки.txt` и переживают обновления и
перезапуски. Пока окно настройки клавиш открыто, сами горячие клавиши не
срабатывают — чтобы назначение новой клавиши не запускало команду.
